# Python network scanner

A simple Python-based network scanner that checks common ports on a target IP address.

## Features

- Scan common ports
- Fast scanning using threads
- Beginner-friendly python project

  ## Technologies Used

- python 3
- socket module
- ThreadPoolExecutor

## How to Run

1. Install Python.
2. Download The Project.
3. Run:

```bash
python network_scanner.py
```

4. Enter the target IP address.
